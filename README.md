# دفتر الدرجات الذكي — النشر والتحديث

## النشر الأول (مرة واحدة)
1. أنشئ مستودعاً على GitHub وارفع كل ملفات هذا المجلد إلى جذره.
2. من Settings ← Pages اختر الفرع main والمجلد root، ثم احفظ.
3. افتح الرابط (https://اسمك.github.io/المستودع/) على الهاتف أو الحاسوب وثبّت البرنامج.
   **لا تغيّر رابط الموقع لاحقاً**: البيانات محفوظة داخل المتصفح لكل رابط على حدة.

## إصدار تحديث جديد
1. عدّل `index.html` (أو أي ملف) كما تشاء.
2. شغّل:  `python bump.py 1.1.0 "إصلاح خطأ الطباعة وإضافة تقرير"`
   (أضف `--manual` إذا لم ترد تطبيقاً صامتاً للتحديث).
3. ارفع التغييرات إلى GitHub (commit + push).

## ماذا يحدث عند المستخدم
- يفحص البرنامج `version.json` عند الفتح وكل ٣٠ دقيقة وعند عودة الاتصال، ويحمّل الملفات الجديدة في الخلفية.
- يظهر شريط «يتوفر تحديث» مع زرّي «تحديث الآن» و«لاحقاً». «لاحقاً» يعني أن التحديث يُطبَّق عند إعادة فتح البرنامج.
- التحديثات الصغيرة (نفس الرقم الرئيسي) تُطبَّق صامتةً حين يغادر المستخدم التطبيق. أما رفع الرقم الرئيسي (مثل 2.0.0) فيتطلب ضغط «تحديث الآن».
- قبل كل تحديث تُحفظ نسخة احتياطية (آخر ٣) داخل البرنامج، وتُستعاد من الإعدادات ← التحديثات.
- التحديث يغيّر ملفات البرنامج فقط؛ قاعدة البيانات (IndexedDB) لا تُمسّ. إن غيّرت بنية البيانات في إصدار لاحق فأضف ترحيلاً داخل الكود يعمل عند التحميل.

## ملاحظات
- يحتاج HTTPS (GitHub Pages يوفره). لا يعمل Service Worker من ملف محلي.
- التخزين المؤقت: ملف `sw.js` يُجلب دائماً من الشبكة، وكل إصدار له كاش مستقل يُحذف القديم عند التفعيل.
